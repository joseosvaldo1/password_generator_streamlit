# Arquitetura do projeto

Este projeto segue uma organização em camadas semelhante ao modelo do projeto de referência.

- app/models/domain.py: regras de domínio e modelos
- app/models/services.py: serviço de geração e avaliação
- app/models/interface.py: interface Streamlit
- main/app.py: ponto de entrada da aplicação
- tests/: validações automatizadas
